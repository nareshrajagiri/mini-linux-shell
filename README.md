# Mini Linux Shell

A minimal Linux shell implemented in C using POSIX system calls.

## Features (Planned)
- Execute external commands
- Built-in commands (cd, exit)
- Process creation using fork and exec
- Signal handling (Ctrl+C)
- Background execution
- Pipes and I/O redirection
- Process monitoring using /proc

## Tech Stack
- Language: C
- OS: Linux (Ubuntu)
- APIs: POSIX
- Build: Makefile
- Tools: gcc, gdb, valgrind

Project initialized. Development in progress.
